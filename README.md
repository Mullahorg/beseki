# Remix of Beseki Showroom

Build a complete, production-quality, modern automotive dealership web application for **BESEKI COMPANY LIMITED**, based in Mombasa, Kenya.

This is NOT a generic template website.

The final result must look like a **real premium car showroom website designed in Figma by a professional UI/UX designer and then carefully hand-coded by an experienced frontend developer**.

The interface must feel:

* Human
* Direct
* Simple
* Premium
* Trustworthy
* Warm
* Modern
* Automotive
* Kenyan/local
* Conversion-focused
* Extremely polished on mobile

Do not make the design look AI-generated.
